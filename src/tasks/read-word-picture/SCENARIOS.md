# Сценарии тестов: «Прочитай слово и выбери картинку»

Описание в терминах предметной области и элементов интерфейса. В тестах привязка по data-testid; озвучку проверяем через мок TTS.

**Элементы интерфейса:** кнопка «Начать», слово по слогам (кнопки с `read-word-picture-syllable-{index}`), блок вариантов картинок (появляется только после прохождения слогов по порядку), подсказка «Слушай задание…».

**Две фазы слогов:** сначала активен только текущий слог по очереди (остальные отключены); после последнего слога открываются картинки, все слоги снова кликабельны для повторного прослушивания.

## data-testid

- `read-word-picture-round` — корневой контейнер раунда
- `read-word-picture-start` — кнопка «Начать»
- `read-word-picture-word` — блок со словом по слогам
- `read-word-picture-syllable-{index}` — кнопка слога (индекс совпадает с частью слова в store)
- `read-word-picture-options` — контейнер вариантов картинок (в DOM только когда показан этап выбора картинки)
- `read-word-picture-option-{id}` — кнопка варианта (id из раунда)
- `read-word-picture-hint` — подсказка «Слушай задание…»

## Сценарий: успешный путь

Раунд: слово МАМА (два слога), варианты с correctId «mama».

1. Пользователь видит кнопку «Начать», нажимает её.
2. Озвучивается инструкция «Прочитай слово и выбери картинку», появляется слово по слогам; контейнера `read-word-picture-options` ещё нет.
3. Пользователь нажимает слоги **по очереди** (0, затем 1): после каждого нажатия озвучивается соответствующий слог.
4. После второго слога появляется блок картинок. Пользователь может снова нажимать любой слог — озвучивается только он.
5. Пользователь выбирает правильную картинку (mama) — озвучивается «Правильно», запрашивается следующий раунд.

## Сценарий: неправильный выбор

1. После старта пользователь проходит слоги по порядку до появления картинок.
2. Пользователь выбирает неправильный вариант.
3. Озвучивается фидбек: «Неправильно. Ты выбрал не ту картинку.» и alt выбранного варианта (как отдельная фраза). Все варианты остаются в раунде; порядок картинок в интерфейсе перемешивается.
4. Блок картинок скрывается; слоги сбрасываются в режим «только по очереди» — снова нужно нажать все слоги по порядку, затем выбрать картинку.
5. Пользователь выбирает правильный вариант — «Правильно», следующий раунд.

**Замечание для тестов:** во время озвучки фидбека при ошибке кнопки слогов и картинок недоступны (`status !== 'idle'`).
